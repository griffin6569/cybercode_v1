# CyberCodeMini Evaluation Benchmarks

This directory contains evaluation benchmarks reserved strictly for model evaluation and zero-shot/few-shot testing.

## Benchmark Datasets

1. **`secbench/`**: SecBench security vulnerability review and remediation benchmark (100 items).
2. **`swe_bench/`**: SWE-bench software engineering coding agent trajectory benchmark (100 items).

> [!NOTE]
> All datasets in `evaluation/` are classified as `evaluation_only` and are prohibited from being included in training candidates (`processed/training_candidates/`).
