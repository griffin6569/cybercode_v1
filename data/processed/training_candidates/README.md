# CyberCodeMini Training Candidates (v0.2.1)

This directory contains the verified training candidates for CyberCodeMini Corpus v0.2.1 (`cybercodemini_train_candidates_v0.2.1.jsonl`).

## Requirements for Training Candidates

An example is eligible to enter this directory ONLY if:
1. Provenance is known and verified.
2. Dataset-level and underlying licensing are verified or cleared under CyberCodeMini policy.
3. The dataset is NOT a protected evaluation benchmark.
4. Security content is explicitly authorized or defensive.
5. No PII or secrets are detected.
6. Quality meets project threshold.
7. Zero overlap with evaluation benchmarks.
